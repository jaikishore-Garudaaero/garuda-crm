# Garuda CRM · RPTO & CoE

Live CRM for the RPTO and CoE sales team: the sales sheet (leads, pipeline, revenue, admissions, CoE labs and IVs) inside one app,
with email marketing, webinars, Google/Meta lead intake, Claude insights and a phone app for field staff.

- Hosting: Vercel (static, `app/`), database and login: Supabase.
- Start here: **SETUP.md** (about 1 hour).
